# 나에게 맞는 군생활 역할 유형 테스트

12문항을 통해 운영·행정형, 기술·통신형, 기동·장비형, 현장·실행형, 교육·리더십형 중 가까운 역할 유형을 탐색하는 정적 웹사이트입니다.

공개 주소: https://roka-nu.vercel.app/

## 로컬 실행

```powershell
python -m http.server 4173
```

브라우저에서 `http://127.0.0.1:4173`으로 접속합니다.

## 안내

- 결과는 진로 탐색용이며 실제 군사특기·보직·부대 배치를 보장하지 않습니다.
- 답변은 서버로 전송하거나 저장하지 않습니다.
- 공식 지원 가능 여부는 병무청 병역진로설계와 최신 모집계획에서 확인해야 합니다.
